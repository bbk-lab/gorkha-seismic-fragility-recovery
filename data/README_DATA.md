# Data provenance
- `raw/gorkha/train_values.csv`, `train_labels.csv` - DrivenData "Richter's Predictor: Modeling Earthquake Damage" training set; derived from the 2015 Nepal Earthquake Open Data Portal survey (Kathmandu Living Labs / Central Bureau of Statistics). Obtained from a public GitHub mirror of the competition files. Check the DrivenData / Open Data Nepal terms before redistribution.
- `raw/osm/pokhara.osm.pbf` - OpenStreetMap extract of Pokhara (2016), (c) OpenStreetMap contributors, ODbL 1.0, from the public GitHub repository PreparePokhara/OSMDataPokhara.
- `processed/` - regenerated by the scripts.
- `external/` - empty; filled by `scripts/fetch_external_data.py` (USGS ShakeMap, Overpass).

# Gorkha survey files (not included)
Download `train_values.csv` and `train_labels.csv` from the DrivenData
"Richter's Predictor: Modeling Earthquake Damage" competition page
(derived from the 2015 Nepal Earthquake Open Data Portal) and place them in this folder.
Please follow the data provider's terms of use.
